01

보따리 신청

상품 조건을 확인한 뒤 수량과 수령 방법을 선택합니다.

  1. 상품 정보 확인

    가격, 신청 마감일시, 기본 수령일, 상세설명을 확인해 주세요.

  2. 수량 선택

    남은 수량과 상품별 최대 신청 수량 안에서 선택할 수 있어요.

  3. 희망 수령일 선택

    수령 가능일부터 일주일 범위 안에서 선택할 수 있어요.

  4. 방문 시간대 선택

    오후 7시 이전 또는 이후 중 방문 예정 시간대를 선택합니다.

준비된 수량이 모두 소진되었다면

수령일까지 대기 신청이 가능해요. 기존 예약건의 취소 수량이 생기면 신청 순번대로 자동 배정되며, 배정 완료 시 알림을 보내드립니다..

02

결제 방식

상품에 따라 현장결제와 선결제 중 선택합니다.

현장결제

수령할 때 결제

  • 입고 완료 후 수령 확인증에 바코드가 표시돼요.
  • 수령 시간대와 관계없이 바코드로 결제해요.
  • 결제 후 수령 완료 슬라이드를 밀어 주세요.
선결제

미리 결제하고 수령

  • 주문자와 입금자명이 다를 때만 입금자명을 입력해요.
  • 결제 확인 전에는 ‘결제 확인 대기’로 표시돼요.
  • 확인 완료 후 수령 완료 슬라이드가 활성화돼요.
선결제 전용 상품

신선식품 등 일부 보따리는 선결제만 가능할 수 있어요. 신청 화면에서 선택 가능한 결제 방식만 표시됩니다.

03

입고 확인과 수령

입고 상태와 수령 확인증을 확인하고 방문해 주세요.

입고 전입고 예정 안내 확인

메인 화면의 입고 상태에서 오늘 수령 상품의 준비 상황을 볼 수 있어요.

입고 완료알림 및 수령 가능 전환

신청한 동일 상품의 주문이 여러 건이어도 입고 알림은 한 번만 전송돼요.

매장 방문수령 확인증 사용

수령 가능 탭에서 신청한 보따리에 맞는 확인증을 열어 주세요.

수령 후완료 슬라이드

물품을 가져간 뒤 직접 수령 완료 처리해 주세요. 처리 시각은 관리자에게 기록됩니다.

방문 시간대

오후 7시 이전 방문

준비된 상품을 직접 확인하고 수령 완료 처리를 해주세요.

방문 시간대

오후 7시 이후 방문

안내된 보관 위치에서 상품을 확인하고 수령 완료 처리를 해주세요.

04

변경·취소·미수령

가능한 시점과 처리 기준이 서로 달라요.

수령일 변경
정상 대기 중이며 지정 수령일이 지나지 않은 주문은 허용된 날짜 안에서 변경할 수 있어요.
고객 직접 취소
보따리 신청 마감 전까지만 가능해요. 취소 수량은 재고로 돌아가거나 첫 대기자에게 우선 배정됩니다.
입금 기한 경과
신청 마감까지 입금 확인이 되지 않으면 주문이 자동 취소될 수 있어요.
미수령 만료
지정 기한까지 현장결제 상품을 수령하지 않으면 바코드가 잠기고 미수령으로 기록될 수 있어요.
현장결제 미수령 3회 누적 시

이후 보따리 신청 화면에서 현장결제 선택이 제한되고 선입금만 이용할 수 있어요. 제한 안내는 수령증이 아니라 신청 단계에서 표시됩니다.

05

알림과 내역 확인

중요한 변경은 알림센터와 웹 푸시로 안내합니다.

  • 입고 알림신청 상품이 입고되었을 때
  • 입금 확인 알림계좌이체 입금이 확인되었을 때
  • 주문 취소 알림관리자 취소 또는 입금 기한 만료 시
  • 재입고·대기 알림재고가 다시 생기거나 대기 수량이 배정되었을 때
  • 문의 답변 알림작성한 문의에 답변이 등록되었을 때
아이폰에서 웹 푸시 받는 방법
  1. Safari에서 오늘의 냉장고를 열어 주세요.
  2. 공유 버튼을 누르고 ‘홈 화면에 추가’를 선택해 주세요.
  3. 홈 화면에 생긴 아이콘으로 다시 실행해 주세요.
  4. 마이페이지의 알림 설정에서 ‘이 기기에서 알림 받기’를 허용해 주세요.

아이폰 Safari 일반 탭에서는 잠금화면 웹 푸시를 받을 수 없어요. 홈 화면에 추가한 웹 앱에서 설정해야 합니다.

안드로이드에서 웹 푸시 받는 방법
  1. Chrome에서 오늘의 냉장고를 열고 로그인해 주세요.
  2. 마이페이지의 알림 설정에서 ‘이 기기에서 알림 받기’를 눌러 주세요.
  3. 브라우저의 알림 권한 창에서 ‘허용’을 선택해 주세요.
  4. 알림이 차단되어 있다면 Chrome의 사이트 설정에서 오늘의 냉장고 알림을 허용해 주세요.

안드로이드는 사이트를 열어 두지 않아도 알림을 받을 수 있어요. 배터리 절전 설정이나 Chrome 알림이 꺼져 있으면 전송이 늦거나 표시되지 않을 수 있습니다.
